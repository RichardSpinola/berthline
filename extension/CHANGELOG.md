# Changelog

## Unreleased

- The status bar shows "Git Log" in a Git project instead of "(neo) Git Graph".

## 0.2.1

- Show Git Log opens (neo) Git Graph.
- This page and the README now show in the editor.

## 0.2.0

- New Java Class dialog with eight kinds of type; it fills in inherited methods and constructors.
- Generate menu: constructor, getter, setter, `equals`/`hashCode`, `toString`, override.
- Postfix completion: `.var`, `.sout`, `.for`, `.if`, `.null`.
- Own icon for each Java type in tabs and tree; tabs no longer show `.java`.
- Build button with Build, Rebuild and Export Runnable JAR.
- One Run button instead of two.
- With the Java profile: files save by themselves after one second, light themes keep their own
  colors, and `fori` leaves a single cursor.
- Web commands moved to their own extension, Berthline Web.

## 0.1.0

- Run, debug, templates, navigation and IntelliJ-style menus for Java.
