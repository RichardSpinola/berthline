# Berthline Hub

The small extension every [Berthline](https://github.com/RichardSpinola/berthline) app carries.

## What it adds

- **Back to Hub** in the status bar (command `berthline.openHub`): returns to the Berthline Hub,
  where apps, projects and settings live.
- **Startup progress**: tells the Hub when the editor is ready, so the boat knows when to stop.
- **Berthline file icons**: a round icon per file type, with its own drawing for Java, HTML, CSS,
  JavaScript (JS), TypeScript (TS), JSON, XML and Markdown. Choose between this pack and the others
  in the Hub, under Customize, or with *Preferences: File Icon Theme*.

It adds no shortcuts.
