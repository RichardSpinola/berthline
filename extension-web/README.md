# Berthline Web

The Web side of [Berthline](https://github.com/RichardSpinola/berthline): one Run button for HTML,
JavaScript and TypeScript.

## What it adds

- **Run**: an HTML file opens in Live Server; JavaScript and TypeScript run on the Node that comes
  with Berthline.
- **Debug**, **Rerun** and **Stop** for the same files.
- **Search Everywhere** and a shortcut to the settings.

## Shortcuts

| Action | Keys |
| --- | --- |
| Run | Shift+F10 |
| Debug | Shift+F9 |
| Run again | Ctrl+5 |
| Stop | Ctrl+2 |
| Search Everywhere | Shift Shift |

## Icons

The file icon pack named Berthline comes with the Berthline Hub extension; pick the pack in the Hub,
under Customize.
