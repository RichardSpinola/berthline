# Changelog

## 0.3.0

- Live preview beside the editor, served from inside the editor: reload on save, CSS swap without
  reload, `npm run dev` support, widths, inspect in both directions, new window and browser.
  Replaces Live Server.
- DevTools docked under the preview, or in a window of its own; page console errors in the toolbar.
- Debug (F5) on HTML finds an installed Chromium-based browser and opens the page at its preview address.
- Insert Block: eight plain HTML blocks with their CSS.
- VS Code keys: F5, Ctrl+F5 and Shift+F5 instead of the IntelliJ ones.

## 0.2.1

- This page and the README now show in the editor.

## 0.2.0

- First version: Run, Debug, Rerun and Stop for HTML, JavaScript and TypeScript, split from the
  Java tools so the Web app carries no Java commands.
