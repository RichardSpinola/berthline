# Roadmap

Each item is an issue in [RichardSpinola/berthline](https://github.com/RichardSpinola/berthline/issues); the board lives in the repository's Projects tab. Area says which part of the project owns it.

Direction: every profile will offer two styles, Berthline (default, inspired by JetBrains IDEs) and VS Code. Until that design lands, the Web profile only gets fixes, not new looks.
