# AI use

Most of Berthline was built with AI: Claude Opus 5.5 and Claude Fable 5.2 (Anthropic), through
Claude Code. They wrote the profiles, settings, Hub, extensions, tests and these docs.

I (Richard Spinola) chose the direction, tested each change on my own computer and decided what to
keep. Every release is tested by the scripts in `tests/` and by hand.

AI features inside the editors are a separate thing: they are off by default and can be turned on
per profile. See [privacy](privacy.md).
