# Privacy and portability

- Profiles, settings and extensions stay inside the Berthline folder.
- The list of trusted folders is stored in `.berthline-shared` in your user folder, and new projects
  go to `Projects` there unless you pick another folder. This is what stays on a shared computer.
- On Linux, the Hub adds a hidden shortcut to your user folder so the taskbar shows the right icon.
- The Hub asks GitHub for new versions when it opens, and sends nothing else. Turn it off in the
  Hub's Settings, under Updates.
- An update is downloaded from the project's GitHub releases and checked against its SHA-256 before
  it is installed.
- Telemetry is always off. AI features are off by default; turn them on per profile under Customize.
