# Web Wherry

The Web profile: HTML, CSS, JavaScript and TypeScript, ready to use.

## What you get

- **Node.js and npm included**, so JavaScript and TypeScript run without installing anything.
- **Live preview** beside the editor: reloads on save, swaps CSS in place, widths for phone, tablet
  and desktop, and a click on an element opens its line in the HTML.
- **DevTools** docked under the preview (Elements, Console, Sources, Network), or in a window of its
  own.
- Projects with a `dev` script (Vite and the like) can run `npm run dev` and show that server.
- **Insert Block**: eight plain HTML sections (navigation, hero, cards, gallery, contact form and
  more), with their CSS added once.
- Run (Ctrl+F5), debug HTML in an installed Chromium-based browser (F5), Prettier on save, ESLint,
  Emmet and a REST client.

## Keys and look

VS Code keys and the editor's own Dark Modern or Light Modern theme. Web Wherry has no keymap choice.

## Under the hood

Berthline's Web extension (`extension-web/`, with its own [README](../../extension-web/README.md))
and the settings in `profiles/web/`.
